VibeCodingHomework 项目规则
==========================

本项目为 AI 编程课作业，需建立一个高级感作品展示网页，并绑定到 GitHub Pages 演示网址。

一、展示网页要求
1. 建立一个作品展示网页，要有高级感
2. 绑定到 GitHub Pages 演示网址，可直接输入网址查看
3. 网页上需展示每个作品的特点（设计目的、特性、功能、特别之处等，非全部必选）
4. 如果是网页作品，需在展示网页上设置演示入口（可点击跳转）

二、项目分类与目录结构
1. 外部项目：另开仓库的作品，在展示网页中以链接形式引用
2. 子项目：专门为完成本课程而创建的作品，放在本项目的子文件夹中
   - 每个子项目在根目录下创建独立文件夹
   - 所有子项目相关文件写入对应文件夹内

三、子项目开发规范
1. 每个子项目需要进行多次提交（Git commit），体现迭代过程
2. 每个子项目目录下必须有一个 progress.md 更新记录文件
3. progress.md 记录内容：
   - 每次用户提供的精简、专业化后的提示词
   - AI 对应的修改细节
   - 版本/时间信息
4. 修改记录需同时写入 Git 提交记录中

四、展示网页内容规范
1. 需展示每个子项目的设计目的、特性、功能、特别之处等
2. 网页作品需设置演示入口链接
3. 外部项目需提供跳转链接
