# StegoTransfer —— 隐写加密传送站点

一个**纯前端、零后端**的文本加密 + 图片隐写站点。所有运算都在浏览器本地完成（Web Crypto API），原文、口令与图片不经过任何服务器。

线上演示：https://www.alexcn.work/Work2/Qoder/ （URL 末尾需带斜杠）

> ⚠️ 本站目前处于**演示期**，页面内含"开发过程"技术文档入口；正式发布时会移除。

---

## 一、产品功能

### 1. 生成密文（加密区）

两种模式，均以弹窗模块从主页进入：

- **纯文本加密**：设置口令（可选有效时间），输入原文，输出一段纯字母数字的 base 密文，可直接复制传送。
- **图片隐写**：先上传图片 → 自动转 PNG 并计算可写入的文本容量（告知约可隐写多少英文字符 / 汉字，并给出选图建议）→ 再输入口令、有效时间（可选）与原文 → **同时输出载密 PNG 和 base 密文**（两者内容等价，可任选一种传送）。

有效时间二选一：**无时效（不过期）** 或 **设定有效时间**（数值 + 单位：秒 / 分钟 / 小时 / 天，范围 60 秒 ~ 3650 天）。到点后使用同一口令也无法解密。

### 2. 还原明文（解密区）

- **纯文本密文**：粘贴 base 密文 + 口令。
- **载密图片**：上传 PNG，自动提取内嵌密文再解密，页面显示提取出的密文（与生成侧逐字符一致）。

时效三态选项（默认"自动"）：

| 选择 | 行为 |
|---|---|
| 自动（推荐） | 按密文内部标记决定试解次序，另一分支兜底 |
| 有时效 | 只按时效参数处理 |
| 无时效 | 只按随机参数处理 |

解密成功时显示原文；有时效密文额外显示**精确到秒的剩余有效时间倒计时**，倒计时结束即宣告过期。

### 3. 其他

- 主页字符雨背景 + ENCRYPT 渐变水印 + 动态模块卡片（极客终端风）
- 全部校验前置：口令非空且一致、原文非空、有效期范围、图片容量超限禁用按钮
- 大图分片处理，错误分类文案，复制失败回退手动全选

## 二、技术细节

### 密码体系

- **KDF**：PBKDF2-HMAC-SHA256 × 100,000 次迭代 → AES-256-GCM
- **密码帧**：版本(1B) + 标志(1B) + IV(12B) + 密文‖tag，整体 base64 后再做盐字段插入
- **盐字段插入**：在 base 密文第 16 个字符后**插入**（非替换）16 字符盐字段 S，接收端按同规则切除复原，保证密文纯字母数字、无 `+/=` 特殊字符，便于人眼传送
- **无时效**：S = 12 字节随机盐的 base32 编码
- **有时效**：S 由 10 字节时效字段编成 base32（仍为 16 字符 `A-Z2-7`，与随机盐字段完全同形，肉眼和统计上无法区分哪段有特殊含义）。字段布局：

  ```
  [1B 随机量 R][4B 有效期(按 R 派生掩码逐字节 XOR)][2B 校验量(R 与有效期绑定)][3B 随机]
  ```

- **时间参数派生**：以加密时刻秒级时间戳为种子，`seed × 15485863 + 982451653` 后 `SHA-256(DOMAIN_SEP:结果)` 参与派生——先乘后加再摘要，避免"看起来特殊"的整数特征
- **绝对过期**（第 8 轮热修复）：加密时将秒级时间戳写入 IV 前 4 字节（大端），解密读出后验签通过再检查 `加密时间 + 设定秒数 > 当前时间`，过期拒绝。剩余时间精确到秒，不受窗口边界对齐影响（旧版"时间戳整除期限"方案在窗口末尾生成时会只剩几秒，已废弃）
- **三态试解**：GCM 验签成功即判定密钥正确；时效字段误读率实测 0/2000，且误判最终仍由验签否决

### 图片隐写

- **量化边缘图**：通道 `& 0xF8` 量化后计算 4 邻域梯度，阈值 16 划分边缘/平坦区——保证加密端与解密端候选像素集**逐像素一致**（收发双方无需共享任何侧信息）
- **LSB Matching ±1**：嵌入抖动不跨量化桶，对视觉几乎无感；alpha 通道固定 255
- **STEG01 帧**：魔数 6B + 版本 1B + 载荷长度 4B（大端）+ 载荷
- **容量公式**：`M_max = ⌊(Ccap − 16) / 4⌋ × 3 − 30`（Ccap 为候选像素数），上传→转 PNG 后即时评估并展示

### 测试

`node test/selftest.js`（Node `crypto.webcrypto` + 合成像素图像）：**31 项断言全部通过**，覆盖：

- 盐字段插入/切除互逆、base32 编解码 0~40 字节往返、时效字段 60~315360000 秒全范围编解码互逆
- 无时效/有时效往返、错误口令拒绝、篡改拒绝、跨时间参数必须失败、同参数区间必须可解、<60s 拒绝
- 隐写往返、量化不变量（嵌入前后候选像素集逐像素一致）、alpha=255、容量边界、端到端（加密→隐写→提取→解密，图中密文与双输出 base64 逐字符相等）

## 三、开发过程

全程由 AI 结对开发（Qoder），每一轮的用户提示词与操作记录留痕在 `progress.md`。首页左下角"开发过程"按钮弹出迭代路线。

| 轮次 | 里程碑 |
|---|---|
| R1 | 需求定稿：盐值方案（时效窗口盐 / 随机盐嵌入第 16-32 位）、图片隐写可选、三段式页面 |
| R2 | 编码实现 crypto.js / stego.js / index.html / app.js，自测 27/27 |
| R3-R6 | 联测修复：隐写比特流偏移、后台标签页 rAF 挂起、base32 尾组漏检；密文改纯字母数字 |
| R7 | 文案脱敏（公开页面不泄露算法细节）；加密增加"无时效"选项 + 时间单位选择；修复载密图无法下载（button→动态 a[download]）；图片限制放宽至 20MB |
| R8 | 时效参数隐藏：补零数字段 → 10 字节 XOR 掩码字段（与随机盐同形）；时效严格化（只试当前时间参数）；先乘后加派生种子 |
| R8+ | 热修复：绝对过期（时间戳入 IV 前 4 字节），剩余时间精确到秒 |
| R9 | 部署上线（nginx alias + home 权限排障，见 deploy.md）；极客风界面改版：模块化弹窗 |
| R10 | 主页动态化：字符雨、ENCRYPT 渐变水印、卡片动效（呼吸辉光/律动条/角标）、像素级对齐、开发过程 modal |

**安全设计取舍**：主站文案与报错经 grep 自检脱敏（不出现算法名、字段位置、窗口机制等）；固定常数仅作混淆而非安全边界；口令必填，空口令禁止（避免退化为纯编码）。
