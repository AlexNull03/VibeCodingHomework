本地加密与图片隐写工具 · 口令 → 密文（可选有效期）→ 文本或 PNG 图片传送
零后端 · 零依赖 · 离线可用 · 全部运算在浏览器本地完成

功能介绍

  • 生成密文：密文为纯字母数字文本，不含特殊字符，可经任意文本通道传送；可设定有效时间，过期后任何人（包括发送者本人）都无法解密。
  • 纯文本加密：输入口令、原文与有效性设置，直接输出密文文本。
  • 图片隐写：上传图片统一转为 PNG 后将密文隐藏写入，实时显示容量并给出选图建议；输出载密 PNG 与等价密文双份。
  • 解密：凭口令与时效选项还原原文；不确定时选"自动"即可。

! DISCLAIMER

  1. 所有运算在浏览器本地完成，本站不收集、不上传任何数据。
  2. 本工具仅供学习与合法用途，禁止用于任何违法活动。
  3. 图片隐写不保证对抗专业隐写分析 / 取证工具。
  4. 载密图片必须以 PNG 原文件传送：压缩、截图、缩放都会导致数据损坏。
  5. 设置了有效时间的密文，过期后发送者本人也无法解密。
  6. 忘记口令无法找回（无后门）。建议口令长度 ≥ 8 位。

DEV LOG · 迭代路线

⚠ 演示期档案：本弹窗含实现细节，正式发布时将整体移除该入口。

R1 · 立项与规格

「创建网站：①生成密文——盐值手动设置为 base 密文的第 16-32 位：有时效则盐值=时间戳整除有效秒数（可加固定值），有效时间秒数（可加固定值）嵌入 16-32 位；无时效则盐值直接随机嵌入。②图像隐写——上传图片转 PNG、计算可写入长度并给选图建议，同时输出载密 PNG 和密文。③页面三段式：介绍+免责声明 / 加密 / 解密；解密提供有时效/无时效/自动三态选项。」

以 detail.md v1.0 为技术规格：盐字段插入（非替换）base64 第 16 字符后、时效窗口盐 window = ⌊ts/duration⌋、混淆常数 K_TS=104729、K_DUR=7919、三态时效试解。建立 progress.md 全程留痕；由 detail.md 生成 target.md（Trae→Qoder）。

R2 · 编码实现

  • crypto.js：PBKDF2-HMAC-SHA256 ×100000 → AES-256-GCM（Web Crypto API，零依赖）。密码帧 = 版本+标志+IV+密文‖tag；无时效盐字段=12B 随机盐 base64，有时效=补零(duration+K_DUR) 共 16 字符；时效密钥盐=SHA-256(DOMAIN_SEP:(window+K_TS))；自动模式按 [随机盐 → 当前窗口 → 前一窗口] 顺序试解，GCM 验签成功即判定。
  • stego.js：量化边缘图（通道 &0xF8 后算 4 邻域梯度、阈值 16）保证收发候选像素集逐像素一致；LSB Matching ±1 且方向不跨量化桶；STEG01 帧（魔数 6B+版本 1B+长度 4B 大端+载荷）；容量公式 M_max=⌊(Ccap−16)/4⌋×3−30。
  • UI：单页三段式 + 选项卡；表单校验、防重复提交、Clipboard 复制回退、大图 rAF 分片。

Node 自测 27/27 通过；端到端联测修复 3 缺陷：提取未按偏移读比特流、后台标签页 rAF 挂起、base32 非规范尾组漏检。

R3–R6 · 连续迭代

密文字符集收敛为纯大写字母数字（base32 编码，可经任意文本通道传送）；时效-only 改版；图片容量评估与选图建议上线；每轮全量回归。

R7 · 体验与隐私改版

「①不需要在任何地方说明我们的任何详细加密和载密原理，因为会帮助攻击者破解；②加密没有'无时效'选项，时效最好给多种单位选择（秒/分钟/小时/天）；③加密图片无法下载，请修正；④选择加密图片时不要加尺寸限制（至少 20M 以下不限）。」

全站文案与报错脱敏（删除 PBKDF2/AES/SHA/base32/盐字段/插入位置/窗口/验签/LSB 等字样），源码注释同步中性化；有效性二选一+单位下拉（内部换算秒，60s~3650 天）；下载修复根因：`<button>` 设 href/download 不触发导航，改为临时 `<a>` 派发 click；上传限制 2MB→20MB、取消 1024×1024 像素限制。

R8 · 时效严格化 + 盐字段去特征

「①时效的意思是把当前时间戳整除期限作为盐值，超过期限盐值变化，应该无法正确解密；②密文 AEARTBYNNNPLGUP700000000000007979D5I6… 里出现这样一截数字肯定让人怀疑有特殊含义——把时间戳整除有效秒数后乘以适当大小的值再加一个不那么特殊的大数，把盐值真正藏起来。」
  • 盐字段重写：10 字节布局 = 随机量 R + 有效期按 R 派生掩码逐字节异或(4B) + R 与有效期绑定校验(2B) + 随机(3B) → base32 后 16 字符，与无时效随机字段完全同形；随机字段误判为有效期实测 0/2000。
  • 时间参数派生改为 SHA-256(DOMAIN_SEP:(window×15485863+982451653))（素数乘数+10⁹量级加数），移除 K_TS/K_DUR。
  • 严格过期：候选由 [当前, 前一窗口] 改为只试当前；自动模式按帧内 FLAG_TIMED 决定次序，避免白跑 10 万次迭代派生，耗时回到约 0.3s。
  • 热修复（「实际有效时间远小于设置值」）：窗口对齐导致设 30 分钟在窗口末尾只剩几秒——改为加密时把精确到秒的时间戳写入 IV 前 4 字节（后 8 字节仍随机），密钥派生用该精确戳不再整除；GCM 验签通过后检查 加密时间+设定秒数 > 当前时间；剩余时间精确到秒。

自测扩充至 31/31（新增全范围编解码互逆、误读率、字段同形、钉时钟跨窗必败/同窗必解）。破坏性变更：旧补零版时效密文不再兼容。

R9 · 部署上线 + 极客风改版

「上传到 www.alexcn.work 的 /home/alex/Work2/Qoder」「访问出现 404」「界面改极客风+模块化，加密解密做成主页模块点击弹窗」「主页加字符雨、ENCRYPT 渐变大字背景、模块放介绍右边、加实时动态特效」
