## 🎯 设计目的

- **练手提示词工程**：以真实产品为目标，验证「四轮迭代式提示词」在低代码 AI 生成平台上的落地效果。
- **打磨日常小工具**：把「记录 → 完成 → 回顾」这条最短闭环做干净，让人愿意每天打开。
- **展示 Vibe Coding 成果**：作为课程作业中的一件完整作品，从 UI 到交互到发布链路，全流程可复现。

> 一句 slogan：**保持专注，从记录第一件事开始。**

## ✨ 核心功能

| # | 功能 | 说明 |
| --- | --- | --- |
| 1 | ➕ 新增任务 | 输入框 + 「添加」按钮，也支持回车快捷提交，新任务自动置顶 |
| 2 | ✅ 勾选完成 | 复选框填充焦糖橙 + 白色对勾，文字加删除线并变灰 |
| 3 | 🗑️ 删除任务 | 每行右侧垃圾桶图标，一键移除，hover 变红提示 |
| 4 | 🔍 筛选切换 | 三个 Tab：**全部 / 进行中 / 已完成**，头部 Badge 实时显示计数 |
| 5 | 💬 空状态文案 | 4 套温馨语境文案动态切换（如「太棒了，所有任务都完成了！」「还没有已完成的任务」） |
| 6 | 📱 响应式布局 | 移动优先，375px 手机与 1280px 桌面均正确无溢出 |
| 7 | 🔔 操作反馈 | 关键动作触发 sonner Toast 提示，成功/失败一目了然 |

## 🎨 视觉与交互设计

### 配色令牌
| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 页面底色 | `#F8F6F2` 暖米白 | 大面积背景，柔和不刺眼 |
| 卡片背景 | `#FFFFFF` 纯白 | 承载内容的主容器 |
| 主强调色 | `#C64D10` 焦糖橙 | Logo、添加按钮、复选框、空状态图标一以贯之 |
| 阴影 | 暖棕色柔和投影 | 让卡片"浮"起来但不生硬 |

### 排版
- **标题字体**：优设标题黑（现代、有力）
- **正文字体**：资源汉圆体（亲和、圆润）
- **圆角规范**：卡片 `16px` / 控件 `12px`，全局一致的柔和曲线

### 微交互
- 卡片错峰淡入，首屏有节奏地"生长"出来
- 按钮 hover 提亮、active 轻微缩放
- 列表项 hover 浅底浮起，删除图标 hover 变红
- 加载时使用骨架屏占位，避免白屏闪烁

## 🌟 特别之处

- **🔁 四轮提示词迭代成型**：从「只写 UI 结构」到「加逻辑」到「加筛选与持久化」再到「打磨体验」，四步稳扎稳打，每一步都可回溯。
- **📱 移动优先设计**：单一 `md(768px)` 断点，先照顾手机再优化桌面，符合真实使用场景。
- **⚡ 乐观更新 + 失败回滚**：操作先行更新 UI，网络异常时自动回滚并弹 Toast 提示，用户体验与数据一致性兼得。
- **♿ 无障碍语义化**：基于 Radix UI 原语构建，复选框、Tab、按钮均带正确的 `role` / `aria-*` 属性，键盘与读屏器可用。
- **🎭 有温度的空状态**：不是冷冰冰的「暂无数据」，而是根据当前筛选上下文切换 4 套文案，让工具也有情绪。
